# 量衡 仪器测量处理

管理仪器、通道、单位、校准证书、观测和测量活动。处理过程保留原值与修订信息，窗口统计、通道对照、量具 R&R 研究和快照导出可追溯到输入。

## 量具 R&R（交叉设计）

量具研究在采集前登记试件、操作员、量具、每格重复次数、允许时段、来源以及可选的公差宽度和过程变差，计划一经开始即不可变。每次可接受观测通过既有的校准修正、单位转换和质量策略后，绑定到一个实验单元（试件、操作员、重复序号）；异常读数不能删除后另开一场试验，漏测、额外重复、记录复用和任何偏离计划的尝试都会进入完整性结果。

* 平衡交叉设计用双因素有重复 ANOVA 给出试件、操作员、试件×操作员交互和重复误差的方差分量；负估计截断为零并显式标记，交互在 5% F 检验不显著时按记录的依据并入重复性。
* 公差占比（六西格玛研究变差除以公差宽度）与过程变差占比（除以外部给定的过程变差）是两个独立口径；总变差为零或未给对应输入时不产生百分比。
* 不平衡或绑定记录已被重放修订时，只输出原始诊断，不套用公式判定合格；平衡研究冻结公式结果，不平衡研究可单独冻结诊断。
* 冻结报告记录输入指纹、证书与每次测量的修订，可追溯到单次观测。


## 运行环境

使用 Python 3.11，核心功能依赖标准库和 SQLite。演示和测试只使用本地合成数据，不需要账户、设备或外部运行服务。请从项目根目录执行命令。

## 检查与运行

构建检查验证语法，测试使用临时数据目录，不会连接远端服务。

```sh
python3 -m compileall -q metrology
python3 -m unittest discover -s tests -v
python3 -m metrology demo
```

演示会展示产品的实际数据处理和输出，运行结束自行退出。查看现有接口：

```sh
python3 -m metrology --help
```

## 目录与数据

metrology/ 保存领域逻辑和请求入口，tests/ 包含正常行为、边界与恢复测试。例子中的标识和记录为合成资料，不包含真实人员或生产测量。业务目录和本地数据库由调用者指定，应与源码分开保存。

## 干净环境复现

容器定义固定运行时版本。构建时准备环境，运行时无需网络；每次启动会复制只读源码到临时工作目录，测试产生的文件不会写回仓库。

```sh
docker build -t local-product-check .
docker run --rm --network none local-product-check
```
